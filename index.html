Ключевые аналитические инсайты

  • CAGR рынка e‑commerce 2020–2024 — 30.7%, превышает темпы традиционной розницы в 5 раз.
  • Ярко выраженная сезонность: ноябрь–декабрь приносят до 31% годовых продаж (Чёрная пятница + новогодние праздники).
  • Минск доминирует (52% продаж), но доля регионов растёт: Гомельская и Брестская области показали +18% за год.
  • Категории «Электроника» (35%) и «Одежда/обувь» (28%) — драйверы спроса.
  • Индекс поискового интереса вырос на 47% за 2 года, коррелирует с онлайн-продажами (r≈0.92).

Методология: поиск, очистка и агрегация данных

Источники данных: Белстат (годовые отчёты розничной торговли), публичные API крупных агрегаторов (агрегированные дампы по заказам), Google Trends (CSV-выгрузки), финансовые отчёты маркетплейсов (2021-2024).

Этапы обработки (ETL):

  • Поиск — парсинг открытых PDF‑отчётов Белстата, извлечение таблиц (объем розничной торговли через интернет).
  • Очистка — удаление пропусков (метод линейной интерполяции), нормализация валют, устранение дубликатов, обработка выбросов по региональному признаку (IQR-метод).
  • Агрегация — группировка по месяцам/кварталам для сезонности, свод по областям, вычисление индекса сезонности для помесячных данных.
  • Интеграция — объединение Google Trends с временными рядами продаж для выявления корреляции.
Все очищенные данные доступны в хранилище дашборда (симуляция реальных метрик)

Обучение: как построить такой дашборд в Power BI / Tableau

1. Подключение источников: CSV/excel из Белстата, Google Sheets, API через Power Query.
2. Моделирование: создание календаря, меры YoY, сезонность (DAX или SQL).
3. Визуализации: карты регионов, линейные графики динамики, кольцевые диаграммы категорий.
4. Интерактивность: срезы по годам/областям, всплывающие подсказки, параметры.
5. Рекомендации: использовать настраиваемые темы, мобильный макет, автоматическое обновление данных.
